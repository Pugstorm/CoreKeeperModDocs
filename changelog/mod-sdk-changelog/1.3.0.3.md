# 1.3.0.3

* Increased the ghost component cap from 256 to 512.
* Made necessary runtime changes to add support for PugText previews in the ModSDK.
* Added an event, ECSManager.BeforeInitialEntityConversion, which can be used in IMod.EarlyInit or IMod.Init to add components to entities before conversion.
* Fixed an issue where an entity using ObjectID.None caused the player's character to hold that entity's representative graphical object in-game even when nothing was selected in the hotbar.
* Fixed an issue where UGC materials weren't being swapped to their runtime variants.
* Fixed an issue where adding required materials beyond the cap resulted in excessive error log spam, which lagged the game.
* Fixed graphical object data block overloads not pooling the correct graphical object.
* Fixed the revealExploredAreas console command so it works again in PC builds.
