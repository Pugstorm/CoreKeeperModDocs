# 1.3.0.5

* Water painted in the ModSDK's custom scene editor now uses its in-game color, making it easier to tell water types apart.
* Tiles without an icon in the ModSDK's custom scene editor now get a button preview generated from their tileset sprite sheet instead of an empty button.
* Added a "Hide Placeable Objects" toggle to the ModSDK's custom scene editor, which hides placed objects in the Scene view so only tiles are visible. This makes it easier to paint tiles in scenes with lots of objects.
* Fixed object IDs of modded objects depending on the order mods were loaded in, which could cause modded objects to get mixed up when the load order changed.
* Fixed Steam Workshop mods still being loaded when launching the game with the no mods option.
* Fixed modded tilesets using a tilesetType value outside the Tileset enum causing other tilesets to go missing.
